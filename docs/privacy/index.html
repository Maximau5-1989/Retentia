Retentia Privacy Policy

Effective date: August 15, 2026

Retentia is a privacy-first Chrome extension that gives selected browser history a configurable expiration date. All processing happens locally on the user's device.

Contact Max wehaveamalfunction@gmail.com

1. Information Retentia accesses

Retentia accesses browser history only to match URLs against user-defined retention rules and remove URLs whose configured retention period has expired.

Retentia may also read the active tab URL when the user explicitly creates a quick rule from the popup or starts a history-based rule action.

2. Information Retentia stores

Retentia stores the following data locally in Chrome's extension storage on the user's device:

  • retention rules
  • settings
  • category overrides
  • protected websites
  • count-only activity summaries
  • count-only scan summaries
  • local password state and password hash
  • authentication delay state

Activity entries and saved scan summaries do not contain deleted URLs or domains.

URL candidates may be held temporarily in memory while the simulator or category review view is open, but they are not written to persistent activity logs or scan history.

Retentia does not create a separate browser-history log file on the filesystem.

3. How Retentia uses information

Retentia uses browser history and local extension storage only to:

  • apply user-defined retention rules
  • remove expired or explicitly selected history entries
  • show local rule and scan results
  • support category scanning and manual review
  • allow protected websites to override deletion rules
  • support password protection for rule management

4. Sharing and transmission

Retentia does not transmit, sell, rent, or share browser history or other personal data with third parties.

Retentia does not use analytics, advertising, account systems, or remote databases.

All core processing takes place locally on the user's device.

5. Optional support link

Retentia may display an optional support button in Settings. The button opens the developer's public PayPal.Me page only after the user explicitly clicks it.

Retentia does not send browser history, rules, settings, or other extension data to PayPal. Any information provided to PayPal after opening that page is processed by PayPal under its own privacy practices.

6. Data retention and deletion

Users can clear the local activity log from the dashboard.

Uninstalling the extension removes its local extension data according to browser behavior. History removed by Retentia cannot be restored by the extension.

The forgotten-password reset deletes the locally stored password hash, retention rules, activity log, authentication-delay state, and last scan summary. It does not delete browser history.

7. Password protection

Retentia includes a local password lock intended to discourage casual access to rule management.

The password lock is not a security boundary against someone with full access to the user's operating-system account, Chrome profile, local extension storage, or browser developer tools.

8. Third-party code

Retentia uses standard open-source frontend and build dependencies, including React, React DOM, Vite, Vitest, TypeScript, and Tailwind CSS.

These dependencies are used only for the local user interface, build process, typing, and tests. They do not send browser history or personal data to external servers.

9. Permissions

Retentia requests the following Chrome permissions only for its local core features:

  • history to read and clean browser history according to user-defined rules
  • storage to save rules and settings locally
  • alarms to run scheduled background cleanup
  • tabs to read the active tab URL when the user creates a quick rule or starts a history-based action
  • contextMenus to provide Retentia actions in Chrome History's right-click menu

10. Changes to this policy

If Retentia's data practices change, this privacy policy will be updated before release.

11. Contact

If you have questions about this privacy policy or Retentia's data practices, contact wehaveamalfunction@gmail.com.
